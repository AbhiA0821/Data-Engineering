## 📚 Learning Modules

### 🗄️ SQL

Relational databases, keys, constraints, SQL commands, CRUD operations, aggregations, joins, subqueries, CTEs, and window functions.

📂 `SQL/`

### 🐍 Python for Data Engineering

File handling, CSV/JSON processing, data cleaning, Pandas, automation, and ETL scripting.

📂 `Python/`

### 🦆 DuckDB

Analytical SQL, Python integration, CSV/Parquet processing, and local analytical workloads.

📂 `DuckDB/`

### ⚡ Apache Spark / PySpark

Distributed processing, DataFrames, Spark SQL, transformations, aggregations, joins, window functions, partitioning, optimization, and ETL pipelines.

📂 `PySpark/`

### 🔄 Apache Airflow

DAGs, tasks, operators, scheduling, dependencies, retries, logging, XCom, and workflow orchestration.

📂 `Airflow/`

### 🐳 Docker

Containers, images, Dockerfiles, volumes, networking, Docker Compose, and containerizing Data Engineering applications.

📂 `Docker/`

### 📡 Apache Kafka

Topics, partitions, brokers, producers, consumers, consumer groups, and real-time data streaming.

📂 `Kafka/`

### ☁️ AWS

Cloud fundamentals and Data Engineering concepts using services such as IAM, S3, and EC2.

📂 `AWS/`

## 🏥 Featured Project — MedIntel

**MedIntel** is an end-to-end Healthcare Data Engineering project used to apply the concepts and technologies learned throughout this journey.

The project focuses on processing patient and vital-sign data through a structured Data Engineering pipeline.

### Technologies

`Python` • `SQL` • `DuckDB` • `PySpark` • `Apache Airflow` • `Docker` • `Kafka`

### Architecture

```text
Patient / Vital Signs Data
            ↓
       Data Ingestion
            ↓
      Data Processing
            ↓
   Cleaning & Validation
            ↓
       Data Storage
            ↓
       SQL Analytics
            ↓
         Dashboard
```

The project demonstrates concepts such as:

- Data Ingestion
- Data Cleaning
- Data Transformation
- Data Validation
- ETL Pipelines
- Workflow Orchestration
- Analytical Processing
- Streaming Data
- Containerization
- Dashboard Integration
