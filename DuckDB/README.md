# 🦆 DuckDB for Data Engineering

> Learning DuckDB for fast analytical SQL processing and local Data Engineering workflows.

## 🎯 Topics Covered

- DuckDB Fundamentals
- Persistent & In-Memory Databases
- Python Integration
- Creating Tables
- INSERT & SELECT
- Filtering
- Aggregations
- CSV Querying
- Parquet Querying
- Analytical SQL

## 💻 Implementation

- `duckdb_basics.py` — Database connection, tables and queries
- `duckdb_analytics.py` — Analytical SQL and aggregations

## 🔄 Data Engineering Use

DuckDB can efficiently analyze local datasets using SQL.

`CSV / Parquet → DuckDB → SQL Analytics → Processed Data`

## 🏥 Application in MedIntel

DuckDB is used as the analytical storage layer for processed patient and vital-sign data, allowing SQL-based analysis and dashboard queries.

## 🎯 Outcome

Use DuckDB with Python and SQL to store, query and analyze data for Data Engineering workflows.
